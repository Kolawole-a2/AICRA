# Legacy scripts

One-off and superseded scripts moved from the repository root during praxis cleanup.

**Use the canonical entry points instead:**

- H1: `python -m aicra.experiments.h1_classification`
- H2: `python -m aicra.experiments.h2_calibration_thresholds`
- H3: `python -m aicra.experiments.h3_evaluation` or `python run_h3_evaluation.py`
- All: `python scripts/run_all_hypotheses.py`
