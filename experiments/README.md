# Legacy experiment scripts (superseded)

These scripts predate the canonical modules in `aicra/experiments/`.

**Use instead:**

| Legacy | Canonical |
|--------|-----------|
| `h1_train_eval.py` | `python -m aicra.experiments.h1_classification` |
| `h2_calibration_eval.py` | `python -m aicra.experiments.h2_calibration_thresholds` |
| `h3_mapping_compare.py` | `python -m aicra.experiments.h3_evaluation` |

See [../docs/praxis/EXPERIMENTS_GUIDE.md](../docs/praxis/EXPERIMENTS_GUIDE.md).
